# 화면 구성 초안

## 1. 화면 설계 원칙

- 첫 화면은 랜딩페이지가 아니라 실제 운영 대시보드다.
- 사용자가 들어오자마자 이번 주에 무엇을 해야 하는지 보여준다.
- 점수는 보조 정보이며, 실행 계획과 부족 역량을 중심에 둔다.
- MVP는 개인용 도구이므로 설정과 입력 흐름을 단순하게 둔다.
- UI는 Next.js, Tailwind CSS, shadcn/ui를 기준으로 구현한다.
- 대시보드, 폼, 테이블, 탭, 모달, 캘린더 중심의 차분한 업무 도구 스타일을 따른다.

## 2. 주요 화면

### Onboarding

처음 사용하는 사용자가 사전 정보를 입력하는 화면이다.

입력 섹션:

```text
기본 프로필
목표 직무 우선순위
지원 시작/취업 목표 시점
평일/주말 가용 시간
기술 스택과 숙련도
인턴/프로젝트/공모전 경험
코딩테스트/자격증/어학 준비 상태
선호 산업과 피하고 싶은 직무
```

결과:

```text
기본 직무 트랙 생성
10개 역량 축 초기 점수 제안
첫 전체 로드맵 제안
이번 주 실행 계획 제안
```

### Dashboard

첫 화면이다.

상단:

```text
목표 직무: 금융 IT 풀스택
지원 시작 D-Day: 2026년 9월 기준
이번 주 가능 시간
이번 주 계획 시간
```

중앙:

```text
이번 주 최우선 목표 3개
오늘 해야 할 일
막힌 점 해결 제안
```

하단:

```text
부족 역량 Top 3
월간 로드맵 진행률
auto-invest 포트폴리오 준비도
공고 마감 임박 항목
```

### Track Readiness

목표 직무 트랙별 준비도를 관리한다.

기능:

```text
직무 트랙 목록
트랙 우선순위
10개 역량 축 점수
증거 메모
목표 점수
AI 개선 제안
```

MVP 구현 상태:

```text
역량별 현재 점수 수정
역량별 목표 점수 수정
증거/메모 수정
대시보드에서 준비도 편집 화면으로 이동
```

### Roadmap

전체 로드맵을 월 단위로 보여준다.

기능:

```text
월간 목표
주요 산출물
진행 상태
우선순위 변경 이력
```

MVP 구현 상태:

```text
로드맵 생성
로드맵 목록 조회
여러 목표 항목을 줄 단위로 입력
대시보드 로드맵 요약 연결
```

초기 로드맵:

```text
2026년 5월 말~6월: 기반 정리
2026년 7월: 취업 자료 제작
2026년 8월: 실전 지원 준비
2026년 9월~2027년 2월: 지원/개선 루프
```

### Weekly Plan

이번 주 실행 계획을 관리한다.

기능:

```text
AI 제안 계획 보기
계획 승인/수정/거절
작업별 예상 시간
작업 상태 변경
주간 총 계획 시간
```

MVP 구현 상태:

```text
주간 계획 생성
작업 항목 줄 단위 입력
주간 계획 목록 조회
작업 todo/done 상태 변경
대시보드 이번 주 목표 연결
```

### Daily Check-In

매일 최소 입력만 받는다.

입력:

```text
오늘 실제 투입 시간
완료한 작업
막힌 점
```

MVP 구현 상태:

```text
일일 체크인 생성
체크인 목록 조회
최근 체크인 대시보드 표시
```

### Weekly Review

주간 회고를 생성하고 다음 주 계획 조정 근거로 사용한다.

판단 항목:

```text
계획 대비 실행률
미완료 원인
다음 주 유지/삭제/조정 항목
준비도 점수 변화
```

MVP 구현 상태:

```text
주간 계획 선택
작업 완료 상태 기반 실행률 계산
미완료 원인/우선순위 조정/점수 변화/요약 기록
회고 목록 조회
```

### AI Suggestions

AI 제안을 생성하고 사용자가 승인/거절한다.

MVP 구현 상태:

```text
설정된 AI Provider 기반 제안 생성
로드맵 제안 생성
주간 계획 제안 생성
주간 회고 제안 생성
공고 분석 제안 생성
제안 목록 조회
제안 승인/수정/거절 상태 변경
제안 JSON 수정 저장
승인한 로드맵 제안 실제 로드맵 반영
승인한 주간 계획 제안 실제 주간 계획 반영
```

### Job Postings

공고를 저장하고 AI로 요약/분류한다.

입력:

```text
공고 URL
공고 본문
메모
```

AI 분석 결과:

```text
회사명
직무명
요구 역량
마감일
트랙 적합도
부족 역량
지원 전 액션
강조할 프로젝트/인턴 경험
```

MVP 구현 상태:

```text
회사명/직무명/URL/마감일/본문 저장
공고 목록 조회
설정된 AI Provider 기반 요구 역량/추천 액션 분석
분석 결과 화면 표시
```

### Calendar

내부 캘린더와 `.ics` 내보내기를 제공한다.

표시 일정:

```text
주간 계획 작업
공고 마감일
자격증 시험일
어학 시험일
주간 회고일
```

기능:

```text
월간/주간 보기
.ics 내보내기
```

MVP 구현 상태:

```text
수동 일정 생성
일정 목록 조회
작업 due_date와 공고 deadline 동기화
.ics 내보내기
```

```text
졸업 예정일
주간 가능 시간
AI 제공자 설정
```
