# 취업준비 도우미 PRD

## 1. 제품 개요

취업준비 도우미는 대학교 소프트웨어학부 4학년 취업 준비생을 위한 개인용 취업 전략 코칭 웹 대시보드다.

초기 사용자는 1명이며, 추후 다중 사용자 서비스로 확장할 수 있도록 데이터 구조는 `user_id` 기반으로 설계한다.

## 2. 핵심 목표

단순 할 일 관리가 아니라, 목표 직무에 맞춰 현재 준비 상태를 진단하고 합격 가능성을 높이는 실행 계획을 제안한다.

서비스의 핵심 흐름은 다음과 같다.

```text
초기 진단
-> 목표 직무 트랙별 준비도 산정
-> 월간 로드맵 생성
-> 이번 주 실행 계획 생성
-> 일일 체크인 기록
-> 주간 회고
-> 다음 주 계획 재조정
```

## 3. 목표 사용자

### 1차 사용자

- 소프트웨어학부 4학년 취업 준비생
- 2027년 2월 졸업 예정
- 2026년 9월부터 본격 지원 예정
- 하루 평균 3~4시간, 주말 5~6시간 취업 준비 가능

### 기본 프로필 항목

학벌과 학점은 준비도 평가 축에 넣지 않고, 기본 프로필과 서류 리스크 분석 요소로 관리한다.

이유는 학벌은 고정값이고 학점은 단기간 실행 계획으로 크게 개선하기 어렵기 때문이다. AI는 이를 점수화된 핵심 역량이 아니라 목표 기업군 대비 리스크와 보완 전략을 판단하는 입력으로 사용한다.

```text
학교
전공
학년/학기
졸업 예정일
전체 학점
전공 학점
총 이수 학점
인턴 경험
공모전 경험
```

### 추후 사용자

- IT/소프트웨어/금융권 개발 직무를 준비하는 취업 준비생
- 개인별 목표 직무, 역량, 프로젝트, 공고, 일정 관리를 원하는 사용자

## 4. 목표 직무 트랙

우선순위는 다음과 같다.

1. 금융 IT 풀스택
2. 백엔드/서버
3. AI
4. 데이터

초기 포지셔닝은 금융 IT 풀스택 개발자다.

```text
TypeScript 기반 금융 SaaS 개발 경험을 바탕으로, 거래 데이터 처리와 API 연동, 실시간 통신, DB 설계 역량을 확장 중인 금융 IT 풀스택 개발자
```

## 5. 준비도 평가 축

각 직무 트랙은 10개 역량 축으로 평가한다.

1. 프로그래밍 언어
2. 백엔드/API
3. DB/SQL
4. 인프라/배포
5. 코딩테스트
6. 포트폴리오/프로젝트
7. 도메인 지식
8. 서류/면접
9. 업무 관련 자격증
10. 어학성적

## 6. 점수 루브릭

각 역량은 0~5 레벨로 평가한다.

```text
0: 경험 없음
1: 따라 해본 수준
2: 간단한 기능 구현 가능
3: 포트폴리오에 설명 가능한 수준
4: 실무/인턴에서 적용한 수준
5: 면접에서 깊게 방어 가능한 수준
```

## 7. 금융 IT 풀스택 기본 가중치

```text
프로그래밍 언어: 12%
백엔드/API: 14%
DB/SQL: 12%
인프라/배포: 10%
코딩테스트: 12%
포트폴리오/프로젝트: 16%
도메인 지식: 10%
서류/면접: 8%
업무 관련 자격증: 4%
어학성적: 2%
```

## 8. AI 우선순위 기준

AI는 다음 기준으로 실행 계획 우선순위를 정한다.

1. 목표 직무와의 관련도
2. 현재 부족도가 큰 항목
3. 남은 시간 대비 개선 가능성
4. 산출물로 증명 가능한지

## 9. MVP 범위

MVP에는 다음 기능을 포함한다.

1. 목표 직무 트랙 관리
2. 10개 역량 축 자가진단
3. 전체 로드맵 생성
4. 이번 주 실행 계획 생성
5. 일일 체크인 기록
6. 주간 회고 생성
7. 공고 URL/본문 저장 + AI 요약/분류
8. 내부 캘린더 + `.ics` 내보내기
9. 초기 온보딩/진단 입력

## 10. 초기 온보딩/진단 입력

지금 grill-me 과정에서 수집한 사전 정보는 추후 여러 사용자가 직접 입력할 수 있는 온보딩 플로우로 제공한다.

온보딩은 사용자의 취업 목표, 현재 상태, 시간 제약, 경험, 선호도를 수집하고 첫 진단과 로드맵 생성을 위한 입력으로 사용한다.

필수 입력:

```text
기본 프로필: 학교, 전공, 학년/학기, 졸업 예정일, 학점
목표 직무: 1~4순위 직무 트랙
목표 시점: 본격 지원 시작일, 희망 취업 시점
가용 시간: 평일/주말 공부 가능 시간
기술 스택: 주 언어, 백엔드, DB, 인프라, 프론트엔드, AI/데이터
경험: 인턴, 프로젝트, 공모전, 포트폴리오
준비 상태: 코딩테스트, 자격증, 어학, 서류/면접
선호/제약: 피하고 싶은 직무, 선호 산업, 선호 기술
```

## 11. MVP 제외 범위

다음 기능은 추후 확장으로 둔다.

- 인증/로그인
- 사이트 자동 공고 크롤링
- Google Calendar 실시간 연동
- 이력서 자동 생성
- 자기소개서 첨삭
- 면접 음성 연습
- 자격증 강의 추천
- 커뮤니티

## 12. AI Provider 전략

MVP는 Gemini 무료 티어를 1순위로 사용한다. 개발/테스트 중에는 비용과 호출 한도 없이 흐름을 검증할 수 있도록 `MockProvider`를 함께 둔다.

AI 기능은 Provider 인터페이스 뒤에 숨긴다.

```text
AIProvider
- generate_roadmap()
- generate_weekly_plan()
- analyze_job_posting()
- generate_weekly_review()

GeminiProvider
MockProvider
OpenAIProvider 또는 기타 유료 Provider
```

AI는 보조 기능이며, 모든 핵심 기능은 수동 작성/수정이 가능해야 한다.

AI 사용 가능:

```text
로드맵 제안
주간 계획 제안
공고 요약/분류
주간 회고 초안
```

AI 없이도 가능한 기능:

```text
로드맵 직접 작성
주간 계획 직접 작성
공고 직접 입력
일일 체크인
주간 회고 직접 작성
역량 점수 수정
```

## 13. AI 코칭 입력

AI 코칭은 다음 데이터를 입력으로 사용한다.

1. 목표 직무 트랙과 우선순위
2. 10개 역량 축의 현재 점수
3. 남은 기간과 주간 가능 시간
4. 현재 진행 중인 산출물
5. 최근 일일 체크인/주간 회고
6. 기본 프로필과 서류 리스크 요소

## 14. AI 코칭 출력

AI 출력은 구조화된 JSON과 사용자용 설명문을 함께 제공한다.

```json
{
  "monthly_goal": "6월에는 auto-invest 포트폴리오화와 SQL/코테 기초 복구에 집중한다.",
  "weekly_plan": [
    {
      "title": "auto-invest README 1차 작성",
      "category": "portfolio",
      "estimated_hours": 4,
      "reason": "금융 IT 포트폴리오 증거를 빠르게 강화할 수 있음"
    }
  ],
  "priority_rationale": "현재는 자격증보다 포트폴리오와 백엔드/API 설명 가능성이 더 중요하다."
}
```

AI가 제안한 계획은 사용자가 승인해야 대시보드에 반영된다.

## 15. 기술 스택

```text
Frontend: Next.js + TypeScript + Tailwind CSS + shadcn/ui
Backend: Python + FastAPI
DB: PostgreSQL
ORM/Migration: SQLAlchemy + Alembic
AI: Gemini 무료 티어 + MockProvider, 추후 유료 Provider 확장
Deployment: 로컬 우선 + Docker Compose 준비, 추후 AWS EC2 또는 Lightsail
Auth: MVP에서는 없음
```

MVP는 단일 사용자 모드로 시작한다.

```text
default_user_id = 1
```

모든 주요 테이블에는 추후 확장을 위해 `user_id`를 둔다.
